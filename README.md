# 小兔的胡萝卜探险

适合 7–8 岁儿童的中文迷宫益智游戏。带小兔沿小路收集所有胡萝卜，再回到小屋。100 个固定且不同的关卡，分为青草小径、蘑菇森林、蓝莓海湾、奶油雪山、星光花园五章，每章 20 关。

## 运行

需要 Node.js 18 或以上，不需要安装依赖。

```sh
npm start
```

打开 http://localhost:5173 。电脑可用方向键或 WASD，手机可点方向按钮、滑动迷宫，也可点小兔相邻格子移动。手机与电脑在同一局域网时，可访问电脑的局域网地址及 5173 端口（需允许本地网络连接）。

## 玩法与进度

- 没有倒计时、生命值、广告、付费或账号。
- 7×7 到 11×11 迷宫，3 到 6 个收集点。第一关就有分支、环路和钥匙门；第 21 关起按数字顺序收集，第 41 关起有两把钥匙和两扇同色门。
- 支持退一步、重新开始、从当前位置计算下一步提示。
- 每关解锁下一关，旧关卡可重玩；100 关通关后可回地图。
- 显示三星目标步数，按路线效率获得 1–3 星，最佳成绩保留；超出目标也可以继续，提示不扣星。
- 自动在当前浏览器 localStorage 保存进度、当前走法和音效偏好。清理浏览器数据或换设备不会保留进度；保存失败时页面会提示。
- 默认关闭音效；可开启短音效。每 20 关切换场景配色。
- 页面以浏览器可用高度布局，迷宫自动适配剩余空间，主游戏无需滚动。地图与帮助弹窗可独立滚动。
- v2 存档保留旧版已解锁进度和星星；因地图改变，旧版未完成关卡从起点重新开始，旧版存档仍保留。

## 验证

```sh
npm run check
```

自动验证全部 100 关的可解性、去重、确定性生成、完整收集条件、从中途提示、撤销、撞墙和存档恢复。`game.js` 是独立游戏逻辑，`app.js` 是界面与存档，`style.css` 提供响应式布局。无外部字体、图片、分析或网络服务依赖。

## GitHub Pages 发布

游戏地址：https://leeweir.github.io/bunny-carrot-adventure/

推送到 `main` 分支后，GitHub Actions 会执行 `npm run check`，仅将游戏所需的五个静态文件打包发布。也可以在 Actions 中手动运行 `Publish game to GitHub Pages`。无需服务器、密钥或付费后端。

线上进度仍保存在当前浏览器中，与 localhost 的存档分开。项目尚未进行真实儿童试玩评估，后续可根据试玩结果调节关卡难度。
